# 下载页：售前咨询、售后服务与社群链接

九流 WP 助手的六种子比下载页视觉方案共享一个联系方式配置。自 v3.0.6 起，插件不再内置开发者的 Telegram 客服或群组网址。

## 后台配置

进入 WordPress 后台 → **九流WP助手 → 下载页美化 → 下载页模板**，找到 **售前咨询与售后服务 · 自定义联系方式**。

- **联系区块标题**：例如“售前咨询与售后服务”，可自行修改。
- **联系说明**：显示在两枚按钮上方，支持普通文本。
- **客服链接**：可填写 `https://t.me/你的客服`、`https://wa.me/...`、`https://你的域名/contact`、`mailto:help@example.com`、`tel:+123456789` 等。
- **客服按钮文字**：例如“咨询客服”。
- **社群／第二联系方式**：可填写论坛、群聊、二线售后或另一种联系方式。
- **第二按钮文字**：例如“加入社群”或“售后工单”。

点击页面底部 **保存下载页模板**。设置与选择的视觉模板一起保存，切换六种风格无需重新填写，也不会影响独立的私有交付设置。

## 默认行为与升级说明

- 新站点的两个 URL 默认都是空的。**不显示联系区块**，不会误导访客联系插件作者。
- 只填写一个 URL 时，只输出对应的按钮；两个都填写时显示两枚按钮。
- 清空 URL 并保存会关闭相应按钮；两个都清空会隐藏整个联系区块。
- 旧版本曾将作者的 Telegram 客服、群组地址固定写在模板中。这些地址不会迁移成任何新站点的默认值。**升级后如需继续显示客服按钮，请站长在本页自行填入自己管理的地址。**
- 输入仅接受以 `https://`、`http://`、`mailto:`、`tel:` 开头的完整地址。脚本、数据 URL 与无协议相对链接不接受。按钮文字在保存及展示时做文本净化／转义。
- 如果你的“网站公告”曾独立写入 Telegram 联系方式，那属于 WordPress 页面自定义字段 `jld_download_notice`，不会被此设置自动替换，请按需手动更新。

## 安全边界

本功能仅控制下载页可见的客服信息和外链按钮，不改变子比订单、会员购买资格、资源提取码、OpenList 私有下载、CDN 缓存及 Nginx 根目录部署规则。建议安装后在实际已购下载页验证按钮地址与联系方式，勿把私有订单链接直接作为公共客服 URL。
