# 九流 WP 助手 · 后台统一设计系统

本规范针对六个功能区及系统设置的后台 UI。**不覆盖前台动画效果、不修改子比主题、OpenList 或 Nginx 服务端授权逻辑。**

## 统一的视觉与行为

- **容器**：12px 圆角、同款细边框和极轻阴影，内边距 16–24px。
- **可选卡片**：统一边框、背景和选中环。悬停只改变边框和背景，**全部禁止抬升、位移、缩放和突然增加大阴影**。原生 radio/checkbox 仍由业务代码控制。
- **表单**：统一 38px 基础输入高度、8px 圆角、按钮 36px、高亮聚焦环。保留原字段名称、类型、Nonce、WordPress 保存接口。
- **按钮**：主操作实心、次操作描边、危险操作红色；悬停仅改变颜色，取消或禁用不能执行业务。
- **选项卡**：同一底板、圆角、已选标签背景；真实选项卡切换仍由对应功能模块脚本执行。
- **通知**：成功绿色、信息蓝色、警告琥珀色、错误红色。成功和普通信息可关闭；警告与错误保留。通知仅显示模块**实际返回**的结果，不因点击保存就提前宣布成功。
- **状态**：徽标与日志结果使用相同色彩语义。Nginx 预览/保护以及匿名探测明确区分成功和失败，不再全部使用同一种蓝色外框。
- **弹窗**：统一使用 Vue 3 + Reka UI 的可访问 Dialog。关闭、Esc、取消均视为拒绝，危险按钮默认优先聚焦“取消”。
- **键盘与无障碍**：保留表单语义、焦点轮廓、减少动画模式，深色主题覆盖模块内部和 Portal 对话框。

## 六大模块覆盖

| 功能区 | 统一内容 |
|---|---|
| 页面特效 | 18 项效果卡片、筛选、配置折叠、状态、表单和保存 |
| 反调试 | 防护分组、选项卡、危险设置、确认弹窗、日志与警告 |
| AI 文章摘要 | API 配置、方案选卡、分类、测试结果、缓存清除与密钥提示 |
| 沉浸式预加载 | 效果卡片、Logo 配置、动态预览外壳、设置与表单 |
| 媒体与链接 | 域名和代理设置、扫描表格、日志、状态、危险批量操作 |
| 子比下载页 | 模板选卡、下载交付配置、Nginx 执行结果、探测和通知 |
| 系统与更新 | 更新确认、检查结果、操作按钮和版本日志 |

## 数据安全与回退

本次改造**不是用 Vue 重写 WordPress 后端**。六个功能模块仍然使用现有 PHP、WordPress 设置 API、REST/AJAX、子比订单、Nginx root 受限助手和 OpenList 本机代理。

危险操作提交必须经过明确的异步确认：媒体模块原生表单确认后通过 requestSubmit 重新进入 WordPress 原 submit 处理器，原有服务端权限验证和 Nonce 不受影响。反调试高风险开关在确认前保持关闭；如果 Vue 无法加载，回退到浏览器原生的保守确认机制。

沉浸式预加载的动态 iframe 和实际预览图片属于内容预览，不修改其内部动画设计，只统一外围对话框。

## 质量门槛

- 组件样式由 src/admin/unified-components.css 统一定义，覆盖六个功能区和系统页。
- 通知语义与关闭交互由 src/admin/unified-notices.mjs 负责，兼容异步插入通知。
- 弹窗状态由 src/admin/dialog-service.mjs 和 ConfirmDialog.vue 统一管理。
- 单元测试涵盖危险确认取消、二次提交、通知语义、模块样式覆盖。
- 浏览器隔离测试页 tests/fixtures/v3-unified.html 验证卡片、通知、弹窗、原生表单操作。
- 正式发布包预编译 Vue 资源；生产站点仍需更新后逐模块验收。
