一个真正统一的 WordPress 增强插件：页面美化、沉浸式预加载、AI 文章摘要、媒体与多域名链接管理。

== Description ==

九流WP助手 2.0 不是把四个旧插件放进同一个目录，而是重新设计成一个完整插件：

* WordPress 只识别一个插件头、一个激活入口和一个更新源。
* 所有后台菜单、页面标题、导航、状态提示和视觉组件由统一控制台负责。
* 四项能力作为内部功能域启动，不再注册各自的插件生命周期、顶级菜单或更新器。
* 保留成熟业务逻辑与旧设置键，升级后无需重新填写 API、动画参数、域名规则和 Logo。
* 在线更新先校验版本和 SHA-256，再完整备份插件目录；失败自动回滚。

四项内置能力：

1. 页面美化：樱花、雪花、灯笼、粒子、鼠标跟随、彩带、灰色模式、右键菜单、背景音乐和自定义代码。
2. AI 文章摘要：多服务商模型、按模型保存 API Key、摘要缓存、动画样式、编辑器操作和访客生成保护。
3. 沉浸式预加载：多种开屏效果、自定义 Logo、最短展示时间、加载完成联动与超时保护。
4. 媒体与链接：媒体相对地址、多域名适配、反向代理诊断、扫描预览、安全修复和 SEO 辅助。

== Installation ==

1. 停用旧的四个独立插件，避免重复输出。
2. 上传九流WP助手插件目录或 ZIP。
3. 启用“九流WP助手”。
4. 从后台左侧“九流WP助手”进入统一控制台。

旧设置会继续沿用；本插件不会在升级时删除现有文章、媒体、AI 缓存或配置。
