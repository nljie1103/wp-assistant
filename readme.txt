将页面美化、媒体相对地址、AI 文章摘要和沉浸式预加载整合为一个可审计、统一更新的 WordPress 工具套件。

== Description ==

九流WP助手是四个九流 WordPress 小型工具的统一维护版本：

* 页面美化 1.6.0：修复动画内存增长、移动端缓存冲突、节日识别、预览权限和长期运行性能问题。
* 媒体相对地址 4.1.1：多域名适配、历史内容扫描、修复中心和响应头诊断。
* AI 文章摘要 1.0.9：多模型摘要、缓存、主题兼容、外观预设，并新增访客生成限流与并发锁。
* 沉浸式预加载 1.0.6：多种加载效果、Logo、时长与跳过策略。
* 统一后台总览和现代化界面。
* 统一从 nljie1103/wp-assistant 更新，不再加载模块独立更新器。
* 更新前校验版本和 SHA-256、完整备份插件目录，失败自动回滚。
* 检测到旧独立插件仍启用时自动跳过对应模块，避免同名类冲突。

== Upgrade Notice ==

从独立插件迁移前，请先停用四个独立版插件，再启用九流WP助手。模块继续使用原 option key，已有设置会保留。
